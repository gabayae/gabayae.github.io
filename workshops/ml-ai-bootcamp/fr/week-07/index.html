Semaine 07 — LLM et IA générative

Module 7 : rouages internes des transformeurs, ingénierie de prompts, fine-tuning LoRA, RAG sur un corpus métier, agents avec usage d'outils.

Ce qu'il y a sous le capot de GPT/Claude/LLaMA, ce que vous pouvez réellement en faire, et où ils échouent.

Choisir une des trois pistes : un système RAG sur un corpus de domaine, un fine-tune LoRA d’un modèle de 1 à 7 milliards de paramètres sur une tâche de domaine, ou un agent multi-étapes utilisant des outils.

Objectifs d'apprentissage

À l'issue de la semaine, chaque participant saura :

  1. Comprendre l’architecture transformer telle qu’elle apparaît dans les LLMs modernes.
  2. Appliquer efficacement les techniques de prompt engineering et de sortie structurée.
  3. Fine-tuner un petit LLM open-source avec LoRA/QLoRA sur un jeu de données de domaine.
  4. Construire un système de génération augmentée par recherche (RAG).
  5. Évaluer honnêtement la génération : quand un LLM est réellement utile, quand il confabule.

Sujets abordés

Le transformer, mécanisme d’attention, scaling laws · pre-training, fine-tuning, RLHF/DPO en survol · prompt engineering, sortie structurée, function calling · fine-tuning efficace en paramètres (LoRA, QLoRA, PEFT) · RAG : chunking, embedding, retrieval, reranking, génération · modèles de diffusion (intuition + usage pratique) · évaluation : BLEU, ROUGE, LLM-as-judge, évaluation humaine, pourquoi toutes sont partielles · systèmes agentiques et utilisation d’outils · sûreté, alignement, hallucination, biais.

Ateliers

Atelier 1 — RAG sur un corpus de domaine

Indexer un ensemble de rapports de santé OMS/AFRO dans ChromaDB. Construire retrieval + reranking + génération ancrée. Évaluer fidélité, pertinence du contexte et exactitude des réponses sur un jeu retenu de 30 questions.

Jeu de données : Rapports PDF OMS/AFRO (accès libre).

Atelier 2 — Fine-tune LoRA sur une tâche de domaine

Fine-tuner Llama 3.1 8B ou Mistral 7B avec LoRA sur un jeu de données de domaine (Q&R médicales, revue de contrats juridiques, ou suivi d’instructions en langue africaine). Reporter la perplexité et une accuracy sur 50 exemples spécifiques à la tâche.

Jeu de données : Choisir parmi trois splits pré-curés.

Atelier 3 — Agent multi-étapes utilisant des outils

Construire un agent avec LangGraph ou function-calling combinant recherche, calculatrice et exécution de code. Stresser sur 20 requêtes multi-étapes et documenter les modes d’échec.

Jeu de données : Synthétique + outils web en direct.
