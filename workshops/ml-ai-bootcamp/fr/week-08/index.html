Objectifs d'apprentissage

À l'issue de la semaine, chaque participant saura :

  1. Versionner code, données et modèles de manière à soutenir la reproductibilité.
  2. Conteneuriser un modèle et le déployer comme API REST.
  3. Mettre en place le tracking d’expériences, le registre de modèles et le monitoring.
  4. Construire un pipeline CI/CD basique pour un système ML.

Sujets abordés

Reproductibilité (Git, DVC, MLflow) · tracking d’expériences et registre de modèles (MLflow, Weights & Biases) · conteneurisation (Docker, docker-compose) · serving (FastAPI, BentoML, registres de modèles) · monitoring (dérive de données, de prédiction, de performance, latence, coût) · CI/CD pour pipelines ML · la différence entre le modèle marche sur mon laptop et le modèle marche en production pendant six mois.

Ateliers

Atelier 1 — FastAPI + Docker + déploiement free-tier

Envelopper un modèle entraîné d’une semaine précédente dans un service FastAPI. Conteneuriser. Déployer sur Render ou Railway. Appeler l’endpoint déployé depuis un nouveau notebook.

Jeu de données : Apportez votre modèle de la semaine 3, 6 ou 7.

Atelier 2 — Tracking MLflow pour une boucle de réentraînement

Mettre en place le tracking MLflow pour une boucle de réentraînement. Logger hyperparamètres, métriques, artefacts. Promouvoir un modèle de staging vers production via le Model Registry.

Jeu de données : Réutiliser un des jeux de données des semaines précédentes.

Atelier 3 — Détection de dérive

Simuler une dérive graduelle des données sur un modèle déployé. Construire un dashboard Grafana ou Evidently qui la détecte. Câbler une alerte qui se déclenche sur un seuil PSI.

Jeu de données : Dérive synthétique superposée aux données d'une semaine précédente.
