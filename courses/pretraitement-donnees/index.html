Prétraitement des données avec Python

Data pre-processing with Python

Yaé Ulrich Gaba

Licence30 heures10 chapitresFR + EN

Description

Un cours pratique qui couvre le pipeline complet de prétraitement des données : chargement depuis sources multiples, gestion des valeurs manquantes, détection des valeurs aberrantes, encodage et mise à l'échelle, ingénierie de variables, prétraitement de texte, données temporelles, construction de pipelines scikit-learn reproductibles. S'appuie sur de vrais jeux de données désordonnés (Titanic, FIFA 21 Raw, Adult Census, Jena Climate).

Prérequis

Python de base et Pandas. Une familiarité avec NumPy et matplotlib est utile.
